# Contributing

1. Create a branch from the latest `main`, such as `feature/new-enemy` or `fix/chest-reward`.
2. Make and test the change locally.
3. Commit with a short description of the outcome.
4. Push the branch and open a pull request into `main`.
5. Merge after the validation check passes. GitHub Pages deploys the updated game automatically.

Keep gameplay changes in small, reviewable commits. Never commit passwords, access tokens, `node_modules`, editor settings, or generated local files.
